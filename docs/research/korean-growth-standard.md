# 한국 성장 백분위 기준 검토

작성일: 2026-04-03  
상태: Draft v1

## 1. 결정 사항
사용자 요청 기준으로 성장 백분위는 **한국 기준**을 사용한다.

## 2. 검토한 방법 3가지

### 방법 1. WHO 기준 사용
- 장점: 국제적으로 널리 알려짐
- 단점: 한국 사용자 기대와 다를 수 있음

### 방법 2. CDC 기준 사용
- 장점: 문서/자료가 풍부함
- 단점: 한국 서비스 기본값으로는 부적절함

### 방법 3. 한국 소아청소년 성장도표 사용
- 장점: 국내 사용자 기대에 부합
- 장점: 국내 의료/건강정보 문맥과 정합성이 높음
- 단점: 기준표 버전 관리가 필요함

## 3. 최종 선택
**선택: 한국 소아청소년 성장도표 기준**

## 4. 공식 출처 기반 판단
질병관리청 국가건강정보포털 문서에서는
- 소아/청소년 비만도 및 성장 평가에
- **2017년 대한소아청소년과학회에서 발표한 한국 소아·청소년 성장도표**를 사용한다고 안내한다.

따라서 현재 제품 문서에서는 기본 성장 백분위 기준을 다음과 같이 둔다.
- `growth_chart_standard = kr_2017`

## 5. 제품 적용 원칙
1. 기본 백분위 기준은 `kr_2017`로 둔다.
2. 기준표 버전은 데이터 모델에서 추적 가능해야 한다.
3. 계산식/기준표 데이터는 하드코딩보다 버전 테이블 또는 정적 데이터셋으로 관리한다.
4. 추후 글로벌 확장 시 WHO/CDC를 추가 지원할 수 있게 확장 가능 구조로 둔다.

## 6. 데이터 모델 반영
현재 문서/SQL 초안에는 아래 반영을 권장한다.
- `households.growth_chart_standard` 기본값: `kr_2017`
- `growth_entries.percentile_source`에 계산 기준 버전 기록 가능
