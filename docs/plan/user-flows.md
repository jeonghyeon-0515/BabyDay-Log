# 상세 사용자 플로우

작성일: 2026-04-03  
상태: Draft v1

## 1. 플로우 설계 원칙
- 각 플로우는 **정상 흐름 / 예외 흐름 / 데이터 반영 결과**를 포함한다.
- 모든 플로우는 현재 선택된 아기 컨텍스트를 전제로 한다.
- 공동양육 및 실시간 반영은 별도 예외 흐름으로 본다.

## 2. 플로우 1 — 최초 사용자 온보딩

### 목표
사용자가 계정을 만들고 첫 번째 아기를 등록한 뒤 바로 기록을 시작한다.

### 정상 흐름
1. 앱 실행
2. 스플래시에서 세션 확인
3. 비로그인 상태면 로그인/회원가입 선택
4. 회원가입 또는 소셜 로그인 완료
5. 첫 아기 등록 화면 진입
6. 아기 이름/생년월일/성별/프로필 사진 입력
7. 홈 화면 진입
8. 빠른 기록 가이드 표시

### 예외 흐름
- 네트워크 실패 → 재시도/오프라인 안내
- 세션 만료 → 로그인 복귀
- 아기 등록 생략 → 홈 진입 불가, 임시 저장 불가

### 성공 결과
- user 생성
- baby 생성
- 홈 대시보드 초기화

## 3. 플로우 2 — 빠른 수유 기록

### 목표
부모가 가장 자주 쓰는 수유 입력을 최소 터치로 기록한다.

### 정상 흐름
1. 홈 또는 기록 탭에서 빠른 기록 버튼 클릭
2. “모유/분유/이유식” 중 선택
3. 필요한 최소 필드만 입력
   - 모유: 좌/우, 시간, 메모(옵션)
   - 분유: 양, 시간
   - 이유식: 종류, 양, 시간
4. 저장
5. 타임라인/홈 요약/위젯 상태 갱신

### 예외 흐름
- 저장 도중 네트워크 단절 → 로컬 큐 보관 후 재동기화
- 공동양육자 동시 수정 → 마지막 수정 시간 기준 병합 또는 충돌 배너

### 성공 결과
- activity_event 생성
- 오늘 요약, 최근 수유 시간, 배고픔 계산값 갱신

## 4. 플로우 3 — 타이머 기반 수면 기록

### 목표
수면/유축/모유수유처럼 길이를 재야 하는 활동을 타이머로 기록한다.

### 정상 흐름
1. 홈/기록에서 수면 타이머 시작
2. 상단 또는 진행 카드에 “진행 중” 상태 노출
3. 사용자는 앱을 떠나도 진행 상태 유지
4. 종료 버튼 클릭
5. 시작/종료 시각 자동 계산
6. 필요 시 메모 수정
7. 저장
8. 분석/인터벌/패턴 데이터 갱신

### 예외 흐름
- 앱 강제 종료 → 로컬 진행 상태 복구 필요
- 사용자가 종료를 잊음 → 종료 시각 수동 편집 허용
- 공동양육자가 다른 기기에서 종료 → 현재 기기 카드 실시간 종료

### 성공 결과
- started_at / ended_at이 있는 이벤트 저장
- 수면 총량 및 인터벌 지표 갱신

## 5. 플로우 4 — 건강/병원 기록

### 목표
체온, 약, 증상, 병원 기록을 남겨 나중에 의료 상담에 활용한다.

### 정상 흐름
1. 기록 탭에서 건강/병원 선택
2. 이벤트 종류 선택
   - 체온
   - 약
   - 증상
   - 병원 방문
3. 수치/메모/사진 입력
4. 저장
5. 타임라인 및 건강 기록 섹션 갱신

### 예외 흐름
- 필수 필드 누락 → 저장 불가
- 사진 업로드 실패 → 텍스트 기록 우선 저장, 이미지 재업로드 큐 처리

### 성공 결과
- 건강 관련 이벤트 생성
- 병원/증상 히스토리 추적 가능

## 6. 플로우 5 — 성장 기록과 발달 체크

### 목표
부모가 성장 추이와 월령별 발달 상태를 확인한다.

### 정상 흐름
1. 성장 탭 진입
2. 키/체중/머리둘레 입력
3. 저장
4. 성장 차트 반영
5. 백분위 표시
6. 발달 체크 화면 이동
7. 월령별 항목 체크
8. 저장

### 예외 흐름
- 과거 날짜 입력 → 시계열 정렬로 반영
- 비정상 수치 입력 → 경고는 주되 저장은 허용 여부 정책 결정 필요

### 성공 결과
- growth_entry 저장
- development_check 저장
- 차트/백분위 계산 업데이트

## 7. 플로우 6 — 공동양육자 초대/합류

### 목표
부모 A가 부모 B 또는 조부모/도우미를 같은 아이 기록에 참여시킨다.

### 정상 흐름 (초대자)
1. 더보기 → 공동양육자 관리 진입
2. 초대 코드 생성
3. 역할 선택(기본 편집 가능)
4. 초대 코드 전달

### 정상 흐름 (참여자)
1. 앱 로그인
2. 초대 코드 입력
3. 아기 정보/초대자 정보 확인
4. 수락
5. 홈에 해당 아기 추가
6. 기록/분석/홈 데이터 실시간 접근 가능

### 예외 흐름
- 만료 코드 → 재요청 안내
- 이미 참여 중 → 중복 참여 차단
- 권한 부족 → 읽기 전용 상태 노출

### 성공 결과
- caregiver_membership 생성
- 초대 상태 consumed 처리
- Realtime 동기화 시작

## 8. 플로우 7 — 다자녀 전환

### 목표
한 계정이 두 명 이상의 아기를 손쉽게 전환한다.

### 정상 흐름
1. 홈 상단 아기 카드 탭
2. 아기 리스트/프로필 시트 노출
3. 다른 아기 선택
4. 홈/기록/분석/일기/위젯 컨텍스트 전환

### 예외 흐름
- 진행 중 타이머가 있는 상태에서 전환 → 경고 후 유지 또는 종료 유도
- 공동양육 권한 없는 아기 접근 → 숨김 처리

### 성공 결과
- selected_baby_context 변경
- 모든 쿼리 범위 전환

## 9. 플로우 8 — 성장일기 작성 및 공개 전환

### 목표
부모가 사진과 글로 성장일기를 남기고, 원하면 공개 일기로 전환한다.

### 정상 흐름
1. 일기 탭 진입
2. 새 일기 작성
3. 사진 첨부 + 텍스트 입력
4. 저장(기본 비공개)
5. 상세 화면에서 “공개로 전환” 선택
6. 공개 범위/주의 안내 확인
7. 공개 완료
8. 커뮤니티 피드에 반영

### 예외 흐름
- 사진 업로드 실패 → 텍스트 일기 우선 저장
- 공개 후 취소 → 피드 비노출, 기존 링크 무효화 정책 필요
- 신고 누적 → 자동 숨김/관리자 검토 필요

### 성공 결과
- diary_entry 저장
- community_post 생성 또는 공개 플래그 반영

## 10. 플로우 9 — 패턴/통계 확인

### 목표
부모가 최근 육아 패턴을 빠르게 파악한다.

### 정상 흐름
1. 분석 탭 진입
2. 오늘/주/월 범위 선택
3. 수유/수면/배변/성장 차트 확인
4. 특정 차트 탭 → drill-down
5. 필요한 경우 기록 탭으로 이동해 원본 이벤트 수정

### 예외 흐름
- 데이터 부족 → 빈 상태 + 기록 유도
- 집계 지연 → 마지막 계산 시각 표시

### 성공 결과
- 사용자는 단순 리스트가 아니라 패턴 이해 가능

## 11. 플로우 10 — 위젯/리마인더

### 목표
앱을 열지 않고도 현재 상태를 확인하고 필요한 시점에 알림을 받는다.

### 정상 흐름
1. 설정에서 리마인더 활성화
2. 수유/수면/기저귀별 조건 설정
3. 홈 위젯 설치
4. 사용자는 위젯에서 마지막 활동/상태를 확인
5. 조건 충족 시 알림 수신
6. 알림 탭 시 해당 기록 입력 화면 또는 홈으로 이동

### 예외 흐름
- 권한 거부 → OS 설정 안내
- 위젯 stale 상태 → 수동 새로고침/백그라운드 갱신 전략 필요

### 성공 결과
- 기록 앱의 반복 진입 비용 감소

## 12. 운영/품질상 중요 플로우

### 데이터 복구
1. 사용자가 새 기기에서 로그인
2. 계정/아기/기록/일기/공동양육 데이터 동기화
3. 최근 선택 아기 복원

### 오프라인 기록 후 재동기화
1. 네트워크 끊긴 상태에서 기록 입력
2. 로컬 큐 저장
3. 네트워크 복귀
4. 순서 보장 업로드
5. 성공/실패 상태 갱신

### 공동양육 실시간 반영
1. 보호자 A가 기록 저장
2. Realtime 이벤트 전파
3. 보호자 B 화면 요약/타임라인 즉시 갱신
