# 육퇴로그 (BabyDay Log)

육퇴로그는 **아기의 하루를 기록하고, 여러 보호자가 함께 공유하며, 패턴과 성장 흐름까지 확인할 수 있는 육아 기록 앱**입니다.

수유 시간만 적는 앱이 아니라,  
**기록 · 분석 · 공동양육 · 성장일기 · 공개 일기 피드**를 한 앱 안에서 제공하는 것을 목표로 합니다.

## 핵심 기능

### 1. 홈 대시보드
- 현재 아기 정보 확인
- 최근 기록 확인
- household 요약 확인
- 주요 생성/입력 흐름 바로가기

### 2. 육아 기록
- 수유
- 수면
- 기저귀
- 건강 / 증상 / 약 / 병원 방문
- 성장 기록
- 메모 기반 activity 기록

### 3. 공동양육
- household 기준 데이터 관리
- 여러 보호자가 같은 아기 데이터를 함께 기록/공유
- 가족 단위 육아 운영 구조 지원

### 4. 아기 관리
- 아기 등록
- 아기 목록 조회
- 생년월일 / 성별 / household 기준 관리

### 5. 분석
- 최근 기록 수 요약
- 이벤트 종류 수 요약
- 최신 기록 타입 / 시각 확인
- 주요 이벤트 분포 확인
- 수유 / 수면 / 기저귀 / 성장 흐름 분석

### 6. 성장 기록
- 키 / 몸무게 / 머리둘레 기록
- 성장 차트
- 발달 체크
- **한국 성장 기준(`kr_2017`)** 기반 백분위 반영

### 7. 성장일기
- 내 일기 목록 조회
- 새 일기 작성
- 비공개 / household 공유 / 공개 범위 선택
- 날짜 기반 회고 기록

### 8. 공개 일기 피드
- 공개 일기 목록 조회
- 공개 일기 하이라이트 확인
- 다른 부모의 공개 기록을 참고할 수 있는 커뮤니티 흐름

### 9. 인증 및 첫 진입 분기
- 로그인 우선순위: **카카오 → 네이버 → 구글**
- 첫 진입 시 아래 순서로 상태 분기
  - 비로그인
  - 프로필 미설정
  - household 없음
  - 아기 없음
  - 준비 완료
